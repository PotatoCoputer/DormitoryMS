Objective

เพื่อประเมินทักษะด้าน:
การออกแบบระบบ
การพัฒนา Full Stack
การออกแบบฐานข้อมูล
UX/UI
Clean Code
การแก้ปัญหาและจัดลำดับความสำคัญของงาน
-------------------------------------------------------------------
Requirement หลัก

1.Authentication
-Login / Logout
-แบ่งสิทธิ์ผู้ใช้งาน (Admin / Tenant)

2.ระบบจัดการห้องพัก
-เพิ่ม / แก้ไข / ลบ ห้องพัก
-แสดงสถานะห้อง
  1)ว่าง
  2)มีผู้เช่า
  3)ปิดปรับปรุง

3.ระบบผู้เช่า
-เพิ่มข้อมูลผู้เช่า
-กำหนดวันเข้าอยู่
-ผูกผู้เช่ากับห้อง

4.ระบบออกบิล
-สร้างบิลรายเดือน
-คำนวณค่าเช่า ค่าน้ำ ค่าไฟ
-เปลี่ยนสถานะการชำระเงิน

5.ระบบแจ้งซ่อม
-ผู้เช่าแจ้งปัญหาได้
-Admin เปลี่ยนสถานะงานได้

6.Dashboard
แสดงข้อมูลภาพรวม เช่น:
-จำนวนห้อง
-ห้องว่าง
-รายได้เดือนนี้
-บิลค้างชำระ
-งานแจ้งซ่อมล่าสุด
-------------------------------------------------------------------
Technical Requirement
-อันนี้เลือกทำเป็น web application

Frontend: (เขาให้เลือก)
เลือกใช้ Framework ได้ตามถนัด เช่น React, Next.js, Vue
-ขอเลือก React

Backend: (เขาให้เลือก)
เลือกใช้ได้ เช่น Node.js, NestJS, Laravel, Django
-ขอเลือก Node.js

Database: (เขาให้เลือก)
MySQL / PostgreSQL / MongoDB
-ขอเลือก PostgreSQL
